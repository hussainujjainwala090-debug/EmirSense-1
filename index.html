Mission

One 90-minute orbit, four operating modes

EmirSense-1 switches modes on a timer, so power-hungry parts like the reaction wheel and LoRa radio only run when the mission needs them.

Design a 1U CubeSat technology demonstrator capable of:

  • Environmental sensing with a BME680 payload
  • Spacecraft health monitoring (power, temperature, light)
  • Attitude stabilization with a reaction wheel
  • Onboard data storage on MicroSD
  • Wireless telemetry and commanding over LoRa

Spacecraft

Built to be printed, assembled and serviced

A PETG frame with four corner rails and removable side panels. Three electronics trays stack on M3 rods, so the whole stack lifts out for wiring and repairs.

Ground segment

Mission control in the browser

The dashboard reads telemetry from a USB-connected LoRa ground station and sends commands back. A built-in simulation runs the full orbit so it works without hardware.

  • Live orbit viewThe CubeSat flies around Earth at its real orbit phase, dims in eclipse and links to the UAE ground station during passes.
  • Two-way commandingEight commands with ACK tracking and one automatic resend.
  • Demo ×10 modeRuns the 90-minute orbit in 9 minutes for judges.
  • Web Serial linkPlug in the ground ESP32 and click Connect in Chrome or Edge. No install needed.
Simulation

Tested in Tinkercad first

An Arduino stand-in for the ESP32 runs the mode logic, reads analogue sensor substitutes and drives the reaction-wheel motor through an H-bridge before any hardware is wired.
